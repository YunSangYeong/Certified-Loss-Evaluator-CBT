# Certified-Loss-Evaluator-CBT

손해평가사 1차 CBT 개발본. **1,000문항 목표 미충족·공식 시험 규칙 확인 대기·배포 중단 상태**입니다. 2차 서술형은 지원하지 않습니다.

전기기능사 CBT의 React/TypeScript/Vite 화면과 모델·저장·가져오기·시험 기능을 고정 커밋 `b9a682ccff1b460334b78d5bfad9375b7ec4fbb6`에서 재사용했습니다. 최신 main `76b990b8720adfa85c22a0a8f699b17094aa357b`의 CBT 표준 **v1.4.0** 폴더 전체를 `.agents/skills/cbt-site-standard/`에 복사했습니다. 기존 AGENTS.md는 없었으며 참조를 새로 연결했습니다. 원본 저장소는 수정하거나 배포하지 않았습니다.

## 실행 및 검증

Node >=22.12 (현재 검증: 24.22.1, npm 11.9.0; 원본 `.node-version` 24.19.0 유지).

```bash
npm ci --cache /tmp/cle-npm-cache
npm run dev
npm test
npm run build
# 이 클라우드의 기존 Chromium 사용. 일반 환경에서는 먼저 npx playwright install chromium
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
python scripts/author_bank.py
```

GitHub Pages base는 `/Certified-Loss-Evaluator-CBT/`입니다. 새 작업에서도 기존 체크아웃을 사용하며 별도 worktree가 필요하지 않습니다. 프로세스는 보존되지 않으므로 필요할 때 dev/preview를 다시 실행합니다.

## 기능

- 실전·랜덤 두 모드, 학습 기준/자료 연도 선택 메뉴 없음. 두 모드 답안 선택 후 Space 이동, 문제 본문 포커스, 미응답·반복키·입력 컨트롤·메뉴·대화상자 보호 및 마지막 문항 자동 제출 방지.
- 5지선다, 절대 종료 시각 기반 90분 타이머, 새로고침 복원·자동 제출·중복 제출 방지, 답안 변경·번호 이동, 과목별 과락을 포함한 채점·해설·오답 복습.
- 랜덤 즉시 채점, 연속 정답·오답노트·북마크·통계·최근 시험, JSON/CSV 등록·검색·페이지 목록·중복 제거·검증 대기·근거를 입력한 로컬 승인·문항 내보내기.
- 자격증별 `loss-evaluator-cbt:v1` 저장 키. 최근 응답 5,000개, 시험 30회. 손상 원본 보존·저장 실패 경고·JSON 백업 내보내기·확인 후 초기화. 기록 복원 UI는 없습니다. 로컬 등록과 승인은 GitHub 공용 은행에 반영되지 않습니다.
- 상시 안내는 사이드바/출처 문서에만 배치. 상단 상시 안내 배너 없음. 고정 모바일 메뉴는 전체 독립 세로 스크롤 및 동적 뷰포트 높이를 사용합니다.

## 시험 규칙과 출처

`src/profile.ts`는 **공식 확인 대기 학습용 설정**입니다: 상법 보험편, 농어업재해보험법령, 재배학 및 원예작물학 각각 25문항, 총 75문항, 90분, 5지선다. 각 과목 100점 환산 40점 이상이고 전체 평균 60점 이상이면 합격. 과목당 1문항 4점이며 미응답은 오답입니다. 표시 점수의 반올림이 아닌 원비율로 판정합니다.

2026-11-08 공식 확인을 위해 다음 주소를 요청했으나 **모두 curl exit 56, CONNECT tunnel failed, response 403**이었습니다. 원문을 읽었다고 주장하지 않으며 최신 법령·공식 규칙·출제기준과의 일치 여부를 확인하지 못했습니다.

- Q-Net: https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=9743
- 국가법령정보센터: https://www.law.go.kr/법령/농어업재해보험법시행령

위 URL은 확인 대상이며 열람한 근거가 아닙니다. 과목의 공식 명칭/범위 및 법령 세부내용과 이용 조건은 공식 자료 접근 후 재확인해야 합니다. 공식 기출 원문과 정답 및 재배포 조건은 확보하지 않았으며 민간 문제를 복제하지 않았습니다.

## 실제 기본 문항 수

| 과목 | 내부 검토 완료 | 검증 대기 | 등록 합계 |
|---|---:|---:|---:|
| 상법 보험편 | 0 | 25 | 25 |
| 농어업재해보험법령 | 0 | 25 | 25 |
| 재배학 및 원예작물학 | 25 | 0 | 25 |
| 합계 | **25** | **50** | **75** |

- 기출 0, 복원 0, 자체 제작 75 (완료 25/대기 50). 계산형 0, 숫자 조건 변형 0, 변형 family 0.
- 검수 완료 1,000문항 대비 **975개 부족**. 50개 초안과 개인 로컬 등록분은 완료 수에 포함하지 않습니다.
- AI 일반 지식 기반 원고입니다. 25개 재배·원예 문항은 질문·정답·오답·설명을 읽고 내부 일관성을 검토했습니다. 정규화 본문/보기 순서 무관 중복 검사 통과. 주제 근접성도 검토했으며 75개가 독립 개념 75개라고 주장하지 않습니다.
- 법령 영역은 공식 원문을 대조하지 못하여 보수적으로 전부 대기로 분류했습니다. 대기 문항은 기본 학습·시험에서 제외됩니다. **기본 은행은 과목별 검수 완료 25개 조건을 만족하지 못하므로 실전 시작이 비활성화됩니다.** 랜덤은 재배·원예 25개로 이용 가능합니다.
- 외부 전문가 검수·최신 공식 출제기준 대조는 미실시. 원고의 저장소 URL은 작성 위치이며 외부 정답 증빙이 아닙니다. 연도·회차는 모두 null. 자체 원고 CC BY 4.0, 코드의 원본 MIT 고지 유지.
- `scripts/author_bank.py`로 고정 순서·ID·보기를 재생성합니다. SHA256 동일 재생성 확인. 무관한 전기 문항은 포함하지 않았습니다.

## 원격 반영 및 배포

기본 workflow: main push → validate(npm ci, 단위, 빌드, PC/모바일) → Pages artifact → deploy. PR은 검증만. deploy만 pages/id-token write 권한을 사용하며 자동 재시도 없음.

**이번 요청의 배포는 사전 네트워크 확인에서 중단됐습니다.**

- 최초 Pages API 요청: `GET https://api.github.com/repos/YunSangYeong/Certified-Loss-Evaluator-CBT/pages`
- 실제 오류: curl exit 56, `CONNECT tunnel failed, response 403`, 프록시 응답 `403 Forbidden` (원격 HTTP 응답은 받지 못해 curl HTTP 000).
- GitHub 인증·쓰기 권한·Pages Source·기존 게시 상태는 미확인입니다. 앱 데이터 미달과 별개인 배포 접근 차단입니다.
- 첫 차단 후 API 재시도·대체 배포·workflow 실행·main 푸시 없음. 구현 보존용 `codex/loss-evaluator-cbt-standard` 브랜치만 대상으로 합니다. 이 브랜치는 push 배포 트리거에 해당하지 않습니다.
- CI/Pages 미실행. 배포 성공 및 공개 화면 확인 증거 없음. 기존 사이트 게시 여부도 미확인.
- 예상 주소(게시 확인 아님): https://YunSangYeong.github.io/Certified-Loss-Evaluator-CBT/

지금 필요한 최소 동작은 **클라우드 환경 설정의 허용 도메인에 `api.github.com` 추가**입니다. 이 조치만으로 GitHub API 인증·Pages 활성화가 보장되지는 않습니다. 첫 차단 이후 마무리는 사용자가 직접 하며, 새로운 명시 요청 없이는 에이전트가 재시도하지 않습니다. 공식 자료 검증에는 별도로 `www.q-net.or.kr`, `www.law.go.kr` 접근이 필요합니다.
